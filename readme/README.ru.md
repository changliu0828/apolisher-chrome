Расширение Chrome, ориентированное на конфиденциальность, которое полирует текст на любой веб-странице с помощью ИИ. Выберите текст, нажмите кнопку полировки и получите улучшенные предложения с ИИ и визуальным сравнением различий.

## Возможности

- **Поддержка нескольких провайдеров ИИ**: Выбирайте между OpenAI, Claude или Gemini, используя свой собственный API-ключ
- **Полировка текста**: Выберите любой текст и отполируйте его с помощью ИИ
- **Несколько пресетов**: Стандартные, профессиональные, нативные, упрощенные, эмоциональный интеллект или пользовательские промпты
- **Быстрое переключение**: Включайте или отключайте расширение из попапа на панели инструментов
- **Визуальные различия**: Просматривайте выделенные изменения с вставками (зеленый) и удалениями (красный)
- **Конфиденциальность прежде всего**: Ваш API-ключ остается локальным, без сбора данных или телеметрии
- **Универсальная совместимость**: Работает на любой веб-странице, включая Gmail, Google Docs и другие

## Установка

### Из исходного кода

1. Клонировать репозиторий:
```bash
git clone https://github.com/changliu0828/apolisher-chrome.git
cd apolisher-chrome
```

2. Установить зависимости:
```bash
npm install
```

3. Собрать расширение:
```bash
npm run build
```

4. Загрузить в Chrome:
   - Открыть `chrome://extensions`
   - Включить "Режим разработчика"
   - Нажать "Загрузить распакованное расширение"
   - Выбрать папку `dist`

## Использование

1. **Настройка**: Выберите своего провайдера ИИ (OpenAI, Claude или Gemini) и добавьте свой API-ключ в настройках расширения
2. **Выбрать**: Выделите текст на любой веб-странице
3. **Полировать**: Нажмите на кнопку <img src="../public/icons/icon32.png" width="16" height="16" alt="Иконка APolish" style="vertical-align: middle;">, которая появляется
4. **Просмотреть**: Посмотрите сравнение различий в модальном окне
5. **Принять**: Нажмите на галочку, чтобы применить изменения

## Конфигурация

Получите доступ к настройкам, нажав на значок расширения или щелкнув правой кнопкой мыши и выбрав "Параметры":

- **Провайдер ИИ**: Выбирайте между OpenAI (GPT-4o Mini), Claude (3.5 Haiku) или Gemini (2.5 Flash)
- **API-ключ**: Ваш специфичный для провайдера API-ключ (безопасно хранится в синхронизированном хранилище Chrome)
- **Пресеты промптов**: Выбирайте между стандартным, профессиональным, нативным, упрощенным, эмоциональным интеллектом или пользовательским
- **Максимум Token**: Контролируйте длину ответа (100-4000 Token, по умолчанию: 2000)

## Технологический стек

- **React** + **TypeScript** - UI-компоненты
- **Vite** - Система сборки с @crxjs/vite-plugin
- **Tailwind CSS** - Стилизация
- **Chrome Extension Manifest V3** - Архитектура расширения
- **Мульти-провайдерный ИИ**: OpenAI (GPT-4o Mini), Claude (3.5 Haiku) или Gemini (2.5 Flash)
- **Shadow DOM** - Изоляция стилей для content script
- **chrome.i18n** - Нативная интернационализация (10 языков)
- **Vitest** + **happy-dom** - Модульные тесты (187 тестов)

## Разработка

```bash
# Установить зависимости
npm install

# Сборка для разработки (с HMR)
npm run dev

# Продакшн сборка
npm run build

# Запустить линтер
npm run lint

# Проверка типов
npm run type-check

# Запустить тесты
npm run test:run

# Собрать и упаковать для Chrome Web Store
npm run package
```

## Структура проекта

```
src/
├── background/      # Service worker для API-вызовов
├── content/         # Content script и UI-компоненты
├── hooks/           # Общий хук настроек
├── i18n/            # Утилиты Chrome i18n и типизированные ключи сообщений
├── options/         # Страница настроек
├── popup/           # Попап на панели инструментов (вкл./выкл.)
├── prompts/         # Пресеты промптов
├── services/        # Мульти-провайдерные сервисы ИИ (OpenAI, Claude, Gemini)
├── test/            # Настройка Vitest, моки и фикстуры
├── types/           # Типы TypeScript
└── utils/           # Утилиты
```
